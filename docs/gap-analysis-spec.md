# 想定ターゲットと実反応のズレ算出仕様（MVP）

## 目的
投稿者が「誰に刺さる想定だったか」と「実際に反応した層」の差を定量で確認できるようにする。

## 入力データ
- expected: 投稿時に設定したカテゴリ集合（1〜3件）
- actual: `欲しいよ` を押したユーザーのカテゴリ分布

## 前提
- 母数は `欲しいよ` のみ（応援/テスターは別指標）。
- カテゴリ未設定ユーザーは `未設定` として別集計。
- 反応数が10未満の投稿は「参考値」バッジ表示。

## 算出手順
1. 投稿ごとの `want` リアクションを取得。
2. 各ユーザーのカテゴリをjoin。
3. カテゴリ別件数と割合を計算。
4. `expected` カテゴリの合算割合を算出（Expected Coverage）。
5. `expected` に含まれないカテゴリの上位3件を算出（Unexpected Top 3）。

## 出力指標
- **Expected Coverage (%)**
  - 定義: expectedカテゴリに該当する `want` の割合
  - 例: expected=ママ/教員, 実績=ママ35%+教員15%=50%
- **Unexpected Top 3**
  - expected外で反応が多いカテゴリ上位3件
- **Category Distribution**
  - 全カテゴリの比率（円グラフ/棒グラフ）

## UI表示ルール
- Coverage 70%以上: 「想定どおり」
- Coverage 40〜69%: 「一部一致」
- Coverage 39%以下: 「想定外の反応が多い」

※ 上記ラベルはMVPの暫定しきい値。運用後に調整。

## 注意点
- 自己申告カテゴリのため、厳密な属性保証はしない。
- サンプル数が少ない投稿で過剰解釈しないため、件数表示を併記する。
