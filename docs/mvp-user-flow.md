# MVPユーザーフロー

## 1. 投稿者フロー

1. 新規登録 / ログイン
2. 投稿フォーム入力
   - 基本情報
   - スクリーンショット2〜5枚
   - 想定ターゲット
   - 公開ステータス
   - （任意）テスター募集
3. 公開
4. ダッシュボードで反応確認
   - 欲しいよ / 応援 / 属性分布 / ズレ
5. 連絡リクエスト対応
   - 承認 or 拒否
   - 承認後メッセージ

## 2. 閲覧者フロー

1. 新規登録
2. 属性を軽く設定（カテゴリ + 自由記述）
3. アプリ一覧から探す
4. 詳細ページを見る
5. 反応する
   - 欲しいよ
   - 応援する
   - テスターになる（募集時）
   - 連絡リクエスト

## 3. 連絡リクエストフロー

1. 閲覧者が用途を指定して送信
2. 投稿者が一覧画面で確認
3. 投稿者が承認した場合のみメッセージ開通
4. 拒否または未承認の場合はメッセージ不可

## 4. 重要KPI（MVP）

- 投稿数（週次）
- 1投稿あたりの「欲しいよ」数
- 「欲しいよ」したユーザーの属性入力率
- テスター応募率（募集ON投稿）
- 連絡リクエスト承認率
- 投稿者の継続投稿率
